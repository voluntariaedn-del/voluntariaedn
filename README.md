# VoluntarIA: Connect & Act

Quero que você crie um NOVO SITE chamado exatamente VoluntarIA.

O projeto antigo que estou fornecendo deve ser usado somente como referência e inspiração para entender a proposta, identidade, organização das telas, experiência do usuário e funcionalidades que já imaginamos.

NÃO considere o projeto antigo como a estrutura obrigatória do novo sistema.

NÃO faça apenas uma cópia, adaptação superficial ou continuação do projeto antigo.

Quero que você pense e desenvolva uma nova versão da plataforma, aproveitando as melhores ideias do projeto anterior e melhorando aquilo que for necessário.

Você possui liberdade para decidir:

tecnologia;

arquitetura;

banco de dados;

autenticação;

armazenamento;

backend;

APIs;

hospedagem;

estrutura de arquivos;

bibliotecas;

serviços externos.

Não siga nenhuma recomendação anterior sobre banco de dados ou plataforma feita por outra pessoa. Escolha livremente a solução técnica mais adequada para construir este projeto.

1. OBJETIVO DA VOLUNTARIA

A VoluntarIA será uma plataforma destinada a aproximar:

pessoas que querem ajudar

de

ONGs, instituições, projetos sociais e pessoas/comunidades que precisam de ajuda.

O objetivo principal é facilitar a descoberta, organização e realização de ações de voluntariado.

A plataforma deverá permitir que uma pessoa não apenas encontre uma ONG, mas consiga encontrar uma forma de ajudar que realmente combine com seu perfil.

2. CONCEITO CENTRAL

O funcionamento principal deve ser:

Pessoa quer ajudar
        ↓
Cria seu perfil
        ↓
Informa habilidades, interesses e disponibilidade
        ↓
Encontra oportunidades
        ↓
Demonstra interesse
        ↓
ONG recebe a solicitação
        ↓
ONG aceita ou recusa
        ↓
Pessoa e ONG entram em contato
        ↓
Voluntariado acontece
        ↓
Ação é registrada
        ↓
Horas/participação são registradas
        ↓
Avaliação e histórico


A plataforma deve funcionar como uma ponte entre necessidade e disponibilidade.

27. INTELIGÊNCIA ARTIFICIAL

A IA é importante para o conceito da VoluntarIA, mas não deve ser apenas um chatbot decorativo.

A inteligência artificial deve ter uma função real dentro da plataforma.

IA MATCH

A IA deve analisar:

interesses;

habilidades;

disponibilidade;

localização;

modalidade;

experiência;

requisitos da oportunidade.

E sugerir oportunidades compatíveis.

Exemplo:

Você informou:

❤️ Educação
🧠 Informática
📍 Indaiatuba
🕐 Sábados
💻 Presencial

Encontramos oportunidades compatíveis.


A IA deve explicar por que cada oportunidade foi sugerida.

Não inventar oportunidades.

O assistente deve utilizar os dados reais disponíveis na plataforma quando estiver procurando oportunidades.
